# Learning opportunity evidence

A topic match is not a mentorship offer. The pilot search explicitly communicates this distinction. Never infer beginner eligibility from keywords, member skills, or engagement.

Proposed future owner-controlled optional participation modes: beginner welcome, structured learning support, existing experience required, unspecified. Keep unspecified as the default for legacy records. A learning-support claim requires an explicit owner declaration and a way to confirm availability. Do not equate a skilled member with a willing mentor.

Before implementation, audit project and opportunity ownership, edit forms, RLS and visibility. Reuse existing edit surfaces; no mandatory fields, new navigation, or additional member onboarding. Prefer explicit relevant learning offers for learning searches, but retain clearly labeled topic discovery. Respect eligibility, expiration, dismissal and existing access restrictions.

Acceptance tests: unspecified never implies beginner welcome; expired or inaccessible offers never surface; owner edits revoke outdated claims; ordinary search unchanged; no individual aspiration persistence without separate consent. Browser and accessibility validation required before release.

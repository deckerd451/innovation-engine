# Opportunity Everywhere pilot release gate

Deliver one working end-to-end external discovery path before adding more matching features.

1. Verify accumulated branch tests and resolve failures. Check branch against main.
2. Review source registry URLs and correct unverified check dates. A provider directory is not a verified opening.
3. Support recurring provider listings separately from deadline-bound openings. Record human review, source provenance, eligibility and expiry/recheck. Do not imply partner endorsement.
4. Reuse existing Home next-step surface behind the disabled-by-default pilot flag. Preserve inbound attention and ordinary Home behavior. External links must be HTTPS, escaped, clearly labeled, and dismissible. No new navigation or required profile fields.
5. Validate mobile, keyboard, screen reader, logout, XSS and authorization behavior. No new production credentials or automatic publishing.
6. Recruit a small consenting pilot cohort. Measure opportunity coverage and self-confirmed participation separately from clicks. Start with five verified actionable listings; expand to 25 after the path works.
7. Obtain release approval before merge, deployment or production writes.

Stop adding isolated features until this path is demonstrated. No claim of verified inventory, successful tests, or production readiness until evidence exists.
